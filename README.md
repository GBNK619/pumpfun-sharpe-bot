A low-variance reversion trading bot for make.fun's Pump.fun Sharpe Sprint: it buys the dip after a real run-up, only while buy flow is still dominant and the dip is stabilising, then exits on a small take-profit, a tight stop, a tight trailing stop, or a stale timer. Small tranches, few trades, tiny drawdown — built for hourly Sharpe on the 6-hour forward window.

## Run it

```sh
node main.ts
```
